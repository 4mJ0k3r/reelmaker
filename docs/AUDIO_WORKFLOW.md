# Audio: current status and the separate workflow

## Status (read this first)

- **`run_reel.py` produces silent MP4s only.** There is no audio option on it. Reels it makes have
  zero audio streams. This is verified on every run (`verification.json` -> `no_audio_stream`).
- Narration, music and sound effects are **not** generated by ReelForge, and are **not** wired
  into the one-command prompt workflow. Adding audio to a prompt-made reel is not tested here.
- The engine does contain an older, separate, audited audio workflow for short episodes.
  It is documented below exactly as the engine defines it; it was not re-tested as part of this
  portable packaging, and it does not use the prompt planner.

## The separate registered-audio episode workflow (existing engine feature)

Facts from `docs/EPISODES.md` and `docs/AUDIO_SYNC.md`:

- An `episode-0.1` manifest has 1-10 ordered 90-frame storyboard segments (3-30 s) and an `audio`
  block. Silent episodes use `episode-0.2` with `"audio": null`.
- Audio is exactly one `AudioPlan`: 48 kHz stereo, AAC (128 kbit/s target), at most **1** registered
  narration cue and at most **4** registered sound-effect cues.
- Every cue start is an **absolute episode frame** (sample start = frame x 1600 at 48 kHz); cues do
  not restart at cuts. Cues running past the end are clipped by the existing rules.
- Audio files must first be **registered**: manifests never contain file paths.

### Steps
1. Obtain your own audio as **PCM16 WAV** files you have the right to use (the engine does not
   create voices or music).
2. Register each file (operator step):
   `python3 tools/register_audio.py <file.wav> --id <snake_case_id> --role narration|sfx`
   (`--help` documents the details and the `--registry-root` option). The registry is `assets/audio/registry.json`.
3. Write an `episode-0.1` manifest (see `examples/episodes/*.json` for complete examples) whose `audio`
   block references the registered ids with absolute start frames.
4. Validate and render:
   `python3 tools/episode.py validate <manifest.json>`
   `python3 tools/episode.py render <manifest.json> --output-dir outputs/my_audio_episode`
   The render refuses an existing output directory and verifies video and audio.

### Timestamps
Timing is expressed only as frame numbers in the manifest (30 fps; frame = seconds x 30). Do not
invent timestamps: if the user has not provided cue times, ask for them or leave the reel silent.

### What ships
`assets/audio` contains three diagnostic tones (`diag_opening` narration-role, `diag_fence` and
`diag_suspense` sfx-role) used by tests and examples. They are test signals, not usable
narration or music.

## Agent guidance
If a user asks for sound, voice-over or music with a prompt-made reel: say the one-command
workflow is silent, offer the silent reel now, and explain that sound needs registered WAV files
and the separate episode workflow above. Do not claim synchronized narration was produced.
